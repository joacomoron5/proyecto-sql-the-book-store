# proyecto-sql-the-book-store
En este proyecto muestro cómo diseñé la estructura de la Base de Datos para "The Book Store" desde cero, creando tablas, atributos y relaciones. Actualmente la estructura está 100% operativa y es el corazón del análisis de datos en TBS. Las tablas fueron pobladas mediante IA con datos artificiales para proteger datos sensibles del negocio.
